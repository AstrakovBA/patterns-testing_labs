# Собиратель монет

Аркадная игра на Python и Pygame, реализованная с использованием ООП и паттернов проектирования. Собирайте монеты, обходите опасности и следите за здоровьем персонажа.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

## Управление

- В одиночной игре — **WASD** или **стрелки** для движения.
- В режиме на двоих — **стрелки** управляют игроком 1, **WASD** — игроком 2.
- **Enter** — выбор пункта меню или настройки.
- **←/→** в настройках — переключение значения.
- **Esc** — возврат в меню.

В меню доступны одиночная игра и соревнование на двоих. В матче побеждает игрок, собравший больше монет к концу игры; при равенстве объявляется ничья. Голубые монеты дают двойные очки, но считаются за одну монету. В настройках доступны звуковые эффекты и обычная/сложная сложность. Значения сохраняются между запусками в `~/.coin_collector/settings.json`; расположение файла можно переопределить переменной окружения `COIN_COLLECTOR_SETTINGS`.
