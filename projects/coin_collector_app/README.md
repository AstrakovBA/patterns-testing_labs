# Собиратель монет

Аркадная игра на Python и Pygame, реализованная с использованием ООП и паттернов проектирования. Собирайте монеты, обходите опасности и следите за здоровьем персонажа.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m pip install -r requirements.txt
python main.py
```

## Управление

- **WASD** или **стрелки** — движение персонажа.
- **Enter** — выбор пункта меню или настройки.
- **←/→** в настройках — переключение значения.
- **Esc** — возврат в меню.

В настройках доступны звуковые эффекты и обычная/сложная сложность. Значения сохраняются между запусками в `~/.coin_collector/settings.json`; расположение файла можно переопределить переменной окружения `COIN_COLLECTOR_SETTINGS`.

## Проверка
